## 2024-05-04 - [Android Auto Backup Vulnerability]
**Vulnerability:** The application was configured to allow automatic backups of all its internal data to the cloud via Android Auto Backup (`android:allowBackup="true"` and `<include domain="file" path="."/>`). This included sensitive data like the internal Room database (`money_visor.db`) containing user's financial transactions and DataStore preferences (`user_prefs.xml`) containing biometric authentication bypass state.
**Learning:** By default, Android backs up app data to the user's Google Drive. If an app stores sensitive user data (like financial records or local authentication flags), this data can be extracted from the backup or transferred to another device, bypassing local security measures.
**Prevention:** Always set `android:allowBackup="false"` unless explicitly required, and configure `data_extraction_rules` and `backup_rules` to carefully exclude sensitive files, databases, and SharedPreferences/DataStore.
